## Capture Rules

- Use synthetic demo files from `docs\demo-data`.
- Hide API keys and personal information.
- Keep the same window size across related screenshots.
- Prefer readable product screenshots over decorative mockups.
- Compress images before committing.
- Keep GIFs short and focused on one workflow.

## When To Add Images To README

Add images to the README only after the files exist in this directory. Do not add broken image links or placeholder image references.
