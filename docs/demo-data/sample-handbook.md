# Northstar Studio Handbook

This is a synthetic handbook for KnowBase demos. The company, policies, and names are fictional.

## Onboarding

New team members complete four onboarding steps:

1. Create a local workspace account.
2. Read the product overview and privacy rules.
3. Upload the approved sample documents into a demo knowledge base.
4. Ask one cited question and confirm that sources appear in the answer.

The onboarding owner is the Demo Operations team. The target onboarding time is 25 minutes.

## Document Handling Policy

Demo work must use synthetic or public-domain documents only. Private resumes, customer files, contracts, API keys, internal school documents, and production databases are not allowed in demo screenshots.

If a screenshot accidentally includes sensitive content, it must be deleted and recreated before publication.

## API Key Policy

API keys are configured by the user and must not appear in screenshots, logs, release notes, or support tickets.

When recording a demo, the API key field should be hidden, blurred, or left empty if the build uses a system fallback key.

## Support Expectations

Support issues should include the app version, operating system version, file type, and a description of the failure. Users should not attach private documents unless a secure support process exists.

Critical launch failures should receive an initial response within one business day. General questions should receive an initial response within three business days.
